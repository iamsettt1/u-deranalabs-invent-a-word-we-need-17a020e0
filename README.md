Invent a Word We Need — a one-word coinage: **doorjog**, the awkward little jog you break into when someone holds a door open for you from twenty metres away. English has no name for the hurried half-jog politeness forces on you when a stranger holds a door from far away. Everyone has done it; nobody had named it — until now.

## Run it

```sh
OUTPUT_DIR=./output python3 main.py
```

The program writes one line to `entry.txt` in the output directory: the invented word **doorjog** and its one-line definition (111 characters, within the 140-character gate).
